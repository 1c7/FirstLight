# 项目结构与开发说明

## 项目结构

```
Package.swift
Sources/LightDose/
  main.swift                 -- NSApplication 启动入口
  AppDelegate.swift           -- NSStatusItem、点击分发逻辑、0.25秒轮询定时器
  MainWindowController.swift  -- 屏幕上的主窗口（左键点击打开）
  AmbientLightSensor.swift    -- IOKit lux 读取，见 doc/1
  DoseCalculator.swift        -- 剂量公式，见 doc/2
  DailyProgressStore.swift    -- 本地 JSON 持久化，按日期分 key
Packaging/
  Info.plist
  build.sh
doc/
  0-同类竞品调研.md
  1-传感器读取原理.md
  2-剂量计算公式.md
  3-项目结构与开发说明.md（本文件）
```

## 界面和交互

菜单栏标题始终显示实时 lux 数值。

- **左键点击**：打开（或关闭）主窗口，展示更大、更完整的信息——当前 lux、今日累计有效分钟 vs 目标（进度条）、达标/未达标状态、按当前亮度估算还需要多少分钟（光线太暗时显示"光线太暗，户外找个开阔地方"代替倒计时）。
- **右键点击**：弹出一个只有"退出"的小菜单。这是唯一能真正退出 App 的入口。
- 关闭窗口（红色按钮）只是把窗口藏起来——App 本身继续在菜单栏后台运行、继续累计今天的剂量。这是靠 `AppDelegate` 里的 `applicationShouldTerminateAfterLastWindowClosed` 返回 `false` 保证的。

## 打包脚本做了什么

`Packaging/build.sh`：

1. `swift build -c release`
2. 把编译产物和 `Packaging/Info.plist` 组装成 `LightDose.app`
3. `codesign --force --deep --sign -` 做 ad-hoc 签名，让 Gatekeeper 不挡着不让在本机打开

没有做公证（notarization），因为这个 App 目前不打算离开开发机分发。

## 为什么不能加 App Sandbox

这个 App 故意**不带任何 sandbox entitlement** 构建。它需要在非沙盒环境下运行才能读到 `doc/1` 里说的那个 IOKit 传感器属性；如果以后加了 entitlements 文件（比如从某个开了 App Sandbox 的 Xcode 模板带过来的），传感器读取可能会**悄悄失效**，不会报错，只是数字不再更新——排查的时候容易漏掉这个原因。

这也是这个 App 没法上 Mac App Store 的直接原因：App Store 强制 App Sandbox，会挡掉 IOKit 访问。

## 开机自启动（可选，目前没做）

为了保持简单，没做开机自启动。想要的话，现代 API 是 `SMAppService.mainApp.register()`（macOS 13+），需要在 `AppDelegate.swift` 里加几行代码、菜单里加个勾选项——目前没接。
