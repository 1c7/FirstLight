# 本地化与界面架构

## 语言行为

FirstLight 支持中文和英语。设置页提供三种偏好：

- **跟随系统**：默认值。每次解析文案时读取 macOS 首选语言列表的第一项；以
  `zh` 开头时使用中文，其余语言使用英语。
- **中文**：忽略系统语言，固定显示中文。
- **英语**：忽略系统语言，固定显示英语。

偏好通过 `UserDefaults` 的 `preferredLanguage` 字段保存。旧版本或首次安装没有该
字段时，`Localization.swift` 返回 `.system`，因此默认行为始终是跟随电脑语言。

用户在设置页切换语言后，`SettingsWindowController` 通知 `AppDelegate`。应用随后：

1. 更新数字格式化器的区域设置；
2. 刷新主窗口、设置窗口和调试窗口；
3. 立即执行一次状态刷新，使存储在模型中的状态与建议文案同步变化。

当偏好为“跟随系统”时，应用也监听
`NSLocale.currentLocaleDidChangeNotification`，系统语言变化后无需重启。

## 添加或修改文案

所有用户可见文案都应调用：

```swift
L10n.text("中文文案", "English copy")
```

不要在具体视图里读取 `Locale.current`，也不要自行读取 `UserDefaults`。数字和日期
格式化器应使用 `L10n.locale`。新增语言选项名称统一维护在
`L10n.languageName(_:)` 中。

## 主窗口分层

- `MainWindowController.swift`：只管理 `NSWindow` 生命周期以及 AppKit/SwiftUI 桥接。
- `MainViewModel.swift`：接收照度和累计分钟，计算所有展示状态与状态文案。
- `MainContentView.swift`：只负责布局、Tab 交互与动画。
- `FirstLightDesignTokens.swift`：集中管理颜色、透明度和通用尺寸。

传感器读取和每日进度持久化不应放进视图或视图模型；它们仍由 `AppDelegate` 协调，
分别委托给 `AmbientLightSensor` 和 `DailyProgressStore`。

## 验证

修改语言解析或界面架构后至少运行：

```sh
swift test
swift build -c release
```

发布前还应在设置页依次切换三种语言，检查主窗口、右键菜单、设置窗口和调试窗口。
